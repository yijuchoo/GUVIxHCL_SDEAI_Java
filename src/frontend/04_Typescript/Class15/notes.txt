Typescript is the superset of javascript that adds the static typing
1. Every JS code is a valid TS code
2. TS will not be understand by the browser
    TS code is converted or compiled into javascript before running in the browser or node js 

TS is the programming language developed by Microsoft

JS
===================
let age = 100;
age = "hello"; // allowed

Error detection will only happen at runtime
Type checking will not happen


TS
==================
let age:number = 25;
age = "hello"; // error

Error detection is at compile time
Type checking will happen always



Installation Steps
=============================
npm init -y
npm install typescript


Check version
-----------------
npx tsc -v
// Version 6.0.3


Create typescript config
--------------------------
npx tsc --init
// Created a new tsconfig.json
// Uncomment the following:
    "rootDir": "./src",
    "outDir": "./dist",

To run the TS
-------------------------
npx tsc
// created a dist folder

node dist/app.js


2. To RUN the TS
npm install -D ts-node typescript

then to run the TS
npx ts-node main.ts

3. To RUN the TS
npm install -D tsx
npx tsx main.ts


Subsequently Just Run the TS as
---------------------------------
npx tsx main.ts


=========================

Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
