Redux: State managementlibrary that stores shared application state in a single store and updates

Redux Store: Centralised object that holds the application state

State: Data used by the application

Action: JS object describing what action happened

Reducer: A function that returns a new state based on the current state and action

Dispatch: Function that sends an action to the redux store
